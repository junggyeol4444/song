# MYVOCAL Studio

내 목소리와 내 캐릭터로 노래와 뮤직비디오를 만드는 프로그램.

지금은 **음악 부분이 동작합니다.** 설명 한 줄을 쓰면 조성·BPM·곡 구조·코드
진행·멜로디·베이스·드럼·반주를 만들고, 피아노롤에서 한 음씩 고치고, 믹싱과
마스터링을 거쳐 음원 파일로 내보냅니다.

---

## 윈도우에서 실행하기

### 1. 파이썬 설치

https://www.python.org/downloads/ 에서 받아 설치합니다.

> 설치 화면 아래쪽 **"Add Python to PATH"** 를 반드시 체크하세요.
> 이걸 빼면 아래 단계에서 "파이썬을 찾을 수 없습니다" 가 나옵니다.

### 2. 실행

`실행.bat` 을 더블클릭합니다.

처음 한 번은 필요한 것들을 자동으로 내려받습니다 (약 300MB, 인터넷 필요).
그 뒤로는 바로 켜집니다.

문제가 있으면 `환경확인.bat` 을 눌러 무엇이 빠졌는지 확인할 수 있습니다.

### 3. 실행 파일로 만들기 (선택)

파이썬 없이 돌아가는 `.exe` 를 만들려면:

```
pip install pyinstaller
python build_windows.py
```

`dist\MYVOCAL Studio\` 폴더가 만들어집니다. **폴더째로** 옮겨야 다른
컴퓨터에서 돌아갑니다. `.exe` 만 따로 옮기면 안 됩니다.

## 화면 없이 쓰기

명령 프롬프트에서:

```
python main.py --song "애니메이션 록 발라드를 만들어줘.
주제: 오래 헤어져 있던 친구를 다시 만나는 이야기
마지막 후렴은 웅장하게." --out 내곡 --format mp3
```

`내곡.mvp` (프로젝트) 와 `내곡.mp3` (음원) 이 만들어집니다.

| 옵션 | 뜻 |
|---|---|
| `--out 이름` | 내보낼 파일 이름 |
| `--format wav24` | 형식 (wav24 / wav16 / flac / flac16 / mp3 / ogg / aiff) |
| `--genre "rock 60 ballad 40"` | 장르를 직접 지정 (기본은 설명에서 읽음) |
| `--seed 42` | 같은 번호를 넣으면 같은 곡이 나옴 |
| `--no-lyrics` | 가사를 쓰지 않음 (기본은 멜로디에 맞춰 작사하고 그 가사로 부름) |
| `--check` | 실행 환경만 확인 |

## 지금 되는 것

**작곡**
- 22개 장르, 비율을 섞을 수 있음 (Rock 50% + K-Pop 30% + Orchestral 20%)
- 기능 화성(으뜸–버금딸림–딸림)에 따른 코드 진행과 종지
- 프레이즈·윤곽·강박 화음음을 지키는 멜로디
- 구간마다 다른 장르·조성·에너지
- "마지막 후렴은 웅장하게" 같은 지시 반영

**작사**
- 멜로디의 음 개수를 세어 줄마다 정확한 음절 수로 가사를 씀
- 같은 선율의 후렴은 같은 가사, 벌스끼리는 다른 가사
- 설명에서 주제(재회, 이별, 그리움, 사랑, 희망, 파티, 밤, 위로)와 장면(비, 바다, 별 ...)을 읽음
- **API 키가 없으면** 내장 규칙으로 작사 — 문법은 맞지만 표현이 딱딱합니다
- **Anthropic API 키가 있으면** Claude 가 작사 — 실패하면 자동으로 내장으로 돌아감
- 가사와 멜로디 음절 수가 다르면 짧은 음을 합치거나 긴 음을 나눠 맞춤
- 결과를 미리 보고 붙임. Ctrl+Z 한 번에 전부 되돌아감

**편곡**
- 베이스 9종, 드럼 12종, 반주 8종 패턴을 장르에 맞게 자동 선택
- 구간 에너지에 따라 악기를 들이고 뺌 (인트로 2개 → 후렴 6개)

**소리**
- 15종 악기 + 22종 드럼을 합성 (샘플 파일 없음)
- 피아노는 줄의 뻣뻣함에서 오는 인하모니시티까지 구현
- 세게 치면 음량만이 아니라 배음이 늘어남

**믹싱 / 마스터링**
- EQ, 컴프레서, 트루피크 리미터, 게이트, 새츄레이션, 잔향, 딜레이
- ITU-R BS.1770-4 라우드니스 측정 (EBU Tech 3341 적합성 시험 통과)
- 스트리밍 기준 음량으로 자동 조절

**노래**
- 한국어 가사를 실제로 부름 (포먼트 합성)
- 표준 발음법 적용 (같이→가치, 독립→동닙, 좋아→조아, 값이→갑씨)
- 6종 목소리 (소프라노~베이스) + 속삭임·파워 창법
- 자음을 박자 앞에 놓아 사람이 부르는 방식과 맞춤
- 입 모양 시간표 생성 (나중에 립싱크가 쓸 것)

**내 목소리 학습 (6·7번)**
- 시작 화면 **내 AI 가수 만들기** 또는 편집기 **도구 → 내 AI 가수**
- 가이드 음을 먼저 들려주고 조용할 때 따라 부르는 방식 — 헤드폰 없이 스피커로도 녹음 가능
- 녹음에서 재는 것: 음역, 모음 포먼트·성도 길이, 숨 섞임(HNR), 밝기, 비브라토(빠르기·폭·시작),
  음 잡는 습관(스쿱), 릴리스, 가이드 대비 음정 오차, 가성 전환점
- 모음 × 음높이(저·중·고) 자료 현황을 표로 보여주고, 부족하면
  "고음의 'ㅣ' 발음 데이터가 부족합니다. 다음 문장을 G4 부근에서 불러주세요." 처럼 안내
- 목소리 모델(누가)과 창법(어떻게: Natural / Ballad / Soft / Power / Rock / Whisper /
  Falsetto / Emotional) 분리. 곡을 만들 때 둘 다 고름, 트랙 머리 오른쪽 클릭으로 바꿈
- 모델을 만든 뒤 그 모델로 다시 불러서 녹음과 측정값이 얼마나 같은지 보여줌
- 목소리는 '내 목소리' 또는 '사용 허가를 받은 목소리' 로만 학습 (63번). 녹음은 사용자 폴더에만 저장
- **한계:** 측정한 성질을 포먼트 합성기 설정으로 옮기는 방식입니다. 신경망 음성 복제처럼
  그 사람의 목소리 결까지 똑같이 재현하지는 않습니다. 실제 사람 녹음으로는 아직 검증하지 못했습니다
  (합성한 가상 목소리로 검증).

**편집**
- 피아노롤에서 음 추가·이동·길이 변경·삭제
- 구간별 가사 입력 (음절 수를 세어 주고 실제 발음을 미리 보여줌)
- 모든 편집 실행 취소 / 다시 실행
- 트랙 음량·좌우 위치·음소거·솔로·악기 변경

**내보내기**
- WAV(16/24/32f), FLAC(16/24), MP3, OGG, AIFF
- MIDI (다른 DAW 에서 열어 편집 가능)
- 트랙별 스템

## 아직 안 되는 것

- 신경망 음성 복제 (지금의 목소리 학습은 합성기 설정을 맞추는 방식)
- 캐릭터 / 사람 등록
- 뮤직비디오, 캐릭터 PV
- AI 학습실

시작 화면에서 이 항목들은 눌리지 않게 해 두었고, 왜 안 되는지 적어 두었습니다.

## AI 서비스 (API 키)

키가 없어도 프로그램은 전부 동작합니다. 키를 넣으면 해당 작업을 바깥 서비스가 합니다.

지금 쓰는 곳: **작사 → Claude (Anthropic)**

넣는 방법 (둘 중 하나):

1. 편집기 메뉴 **도구 → AI 서비스 설정...** 에서 키 입력 후 저장
2. 환경 변수 `ANTHROPIC_API_KEY` 설정 (설정 창보다 우선)

- 키는 프로젝트 파일(.mvp)에 들어가지 않습니다. 사용자 폴더의 설정 파일에만 저장됩니다
  (`%APPDATA%\MYVOCAL Studio\settings.json`).
- 모델은 설정 창에서 고를 수 있고, 비워 두면 계정에서 쓸 수 있는 가장 최근 모델을 씁니다.
- 쓴 만큼 Anthropic 계정에 청구됩니다. 작사가 끝나면 쓴 토큰 수를 보여 줍니다.
- `anthropic` 패키지가 필요합니다: `pip install anthropic`

## 소리가 안 나올 때

메뉴의 **도움말 → 소리 장치 확인** 을 눌러 보세요.

소리 장치를 못 찾아도 곡을 만들고 파일로 내보내는 것은 됩니다. 그 경우
재생 버튼을 누르면 위치만 움직이고 소리는 안 납니다.

## 만든 것이 어떻게 저장되는가

`.mvp` 파일 하나에 전부 들어갑니다. 조성, BPM, 곡 구조, 모든 트랙과 음,
가사, 믹서 설정까지. 사람이 읽을 수 있는 형식(JSON)이라 나중에 프로그램이
없어도 내용을 꺼낼 수 있습니다.

**완성된 음원 한 덩어리로 만들지 않습니다.** 드럼만 빼거나 베이스 한 음을
고치는 것이 언제든 됩니다.

## 코드 구조

```
myvocal/
  core/        프로젝트 문서, 음, 트랙, 시간 좌표계, 실행 취소
  music/       음악 이론, 장르, 곡 구조, 화성, 선율, 편곡, 악기, 작곡
  audio/       버퍼, DSP, 라우드니스, 오실레이터, 분석, 렌더링, 재생, 내보내기
  voice/       한국어 발음, 음소, 노래 합성
  providers/   바깥 서비스와 내장 기능을 같은 모양으로 (키 없으면 내장으로)
  ui/          시작 화면, 피아노롤, 타임라인, 트랙 목록, 조작부, 메인 창
tests/         검증 (전부 손계산·이론값·국제 표준 기준)
```

음악·목소리·캐릭터·영상이 **하나의 프로젝트 문서와 하나의 시간 좌표계**를
공유합니다. 그래야 "후렴부터 밤거리로 나가게 해줘" 같은 요청을 처리할 때
후렴이 몇 초인지와 그 시각에 어떤 장면이 있는지를 같은 자리에서 알 수 있습니다.

```
python tests/test_units.py        시간 좌표계
python tests/test_theory.py       음악 이론 (155개)
python tests/test_audio.py        오디오 엔진 (134개)
python tests/test_instruments.py  악기 (224개)
python tests/test_project.py      프로젝트 문서 (183개)
python tests/test_export.py       내보내기 (114개)
python tests/test_voice.py        노래 합성 (125개)
python tests/test_voice_learning.py  목소리 분석·학습·창법 (89개)
python tests/test_providers.py    작사 · Provider · 설정 (250개)
python tests/test_ui.py           화면 (163개)
```

기대값은 코드가 뱉은 값이 아니라 손으로 계산한 값, 음악 이론 교과서 값,
국제 표준(EBU Tech 3341)의 적합성 시험값입니다.
